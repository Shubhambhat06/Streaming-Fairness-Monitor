# 3-minute demo video

`streaming_fairness_monitor_3min_demo.mp4` is an approximately 3-minute narrated presentation video, assembled from project architecture, metric definitions, and the **actual synthetic pilot CSV**. It is **not a live screen capture** of Flink or Streamlit, because Docker was not executed in the creation environment. The dashboard depiction is illustrative and is labeled as such in the video.

For an in-class live demonstration, follow `docs/DEMO_SCRIPT.md` to show the real UI locally. Do not claim that the video proves the full Docker pipeline has run.
